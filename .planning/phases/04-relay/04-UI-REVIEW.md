The review checked safe boundary settlement and fatal-hazard priority before
fresh-confirmed transfer; closed roster and original-slot reclaim; inactive
loss continuing play versus active loss freezing for explicit action; waiting
when only reclaimable seats remain; and terminal handling when none remain.

The owner-labelled hand/market remains a single tree with active-runner-only
transactions and owner-change invalidation. Innate 100-block and personal
250-tile meters remain separate and gain only from the participant's earned
movement. Results use an immutable leg ledger and true equal-distance ranks.

The contract requires purposeful compact/short pages without scrollbars,
large controls, both runtime themes, reduced motion, and muted browser proofs.
This is design-contract approval, not implementation or visual-proof completion.
