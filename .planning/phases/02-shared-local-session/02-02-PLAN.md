<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Concurrent player contacts → shared pickup authority | Multiple untrusted action paths contend for one mutable reward. |
| Shared world → per-player effects | One world applies resolved mob/reward outcomes to independently owned player state. |
| Device lifecycle → mode handler | Hardware absence/reclaim is reported as data; the mode decides policy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Tampering | pickup arbitration | high | mitigate | Immutable claims, once-only world resolution, stable documented tie-break, and reversed-order tests. |
| T-02-06 | Denial of Service | roster-sized world update | high | mitigate | One world/director update independent of roster size with 1/2/4-player state comparisons. |
| T-02-07 | Tampering | death inventory ownership | high | mitigate | Player-scoped spill/clear path plus assertions that every other inventory remains unchanged. |
| T-02-08 | Spoofing | device loss as death/departure | medium | mitigate | Typed disjoint lifecycle transitions and tests forbidding inventory/identity mutation on device events. |
| T-02-SC | Tampering | package supply chain | low | accept | No package or lockfile change occurs. |
</threat_model>
