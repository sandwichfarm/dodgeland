## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Device join gesture → seat claim | An untrusted edge may attempt to allocate or act in the same frame. |
| Session state → setup/HUD DOM | Mutable gameplay observations become focusable status UI. |
| Runtime frame/theme → responsive surface | Host-controlled dimensions and theme can hide controls or produce overflow. |

| T-02-16 | Tampering | join edge | high | mitigate | Consume claim edge, require neutral, and separately test later action delivery. |
