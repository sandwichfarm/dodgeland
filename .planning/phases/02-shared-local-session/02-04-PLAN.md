<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native iframe key event → seat action | Untrusted key identity and browser repeat state enter one player profile. |
| Binding editor → live router/storage | User-proposed maps must validate atomically before affecting gameplay. |
| Napplet → shell shortcut lease | App closes and restores only registrations it owns. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-11 | Spoofing | key/profile routing | medium | mitigate | Resolve normalized supported keys through one validated profile map and stable seat assignments. |
| T-02-12 | Tampering | persisted bindings | medium | mitigate | Parse/version/validate the complete map and retain defaults on malformed or unavailable storage. |
| T-02-13 | Denial of Service | duplicate bindings/stale latches | high | mitigate | Reject conflicts atomically and clear/seed latches across capture, focus, and teardown transitions. |
| T-02-14 | Elevation of Privilege | shell shortcut ownership | high | mitigate | Close only recorded app-owned handles; use no host DOM or new protocol surface. |
| T-02-SC | Tampering | package supply chain | low | accept | This plan installs no package and requires an unchanged lockfile. |
</threat_model>
