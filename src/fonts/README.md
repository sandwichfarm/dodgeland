# Pause board type

`LilitaOne-Regular.ttf` is the unmodified Lilita One font by Juan Montoreano,
from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/lilitaone).
It is distributed under the SIL Open Font License 1.1 in
`LilitaOne-LICENSE.txt`; copyright and license metadata are also present in the
font itself. The original font is bundled in the napplet artifact, with no
runtime font request. Its use is scoped to the paused game board.
